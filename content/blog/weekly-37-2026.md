-  Plugin to replay zoom chat transcript

    To enjoy the banter in the talk I mentioned above, I created a [bookmarklet](https://punchagan.github.io/bookmarklets/#zoom-chat-replay) that
    allows me to watch the transcript of any zoom recording replayed alongside the
    video, when they are both uploaded to Google Drive with public access
    permissions.

    I started writing it by hand as an exercise in not using any AI assistance, but
    I ran out of time allotted and wanted nicer looking UI and better UX for the
    replay which Claude was able to help finish, for me. Writing the code to parse
    the chat transcript (by hand) took longer than expected because of
    inconsistencies in the transcript that Zoom generated.

-  Blog newsletter needed a fix

    I had a spam sign-up on the newsletter, but hadn't had the time to remove it
    before the newsletter scheduled time. The send failed because the email ID was
    an @example.com email address. Resend catches these and refuses to broadcast
    (send) to an audience that includes such an email ID.

    ```json
    {
      "statusCode": 422,
      "message": "The audience you are sending contains a contact with an email address ending in `@example.com`. Please use our testing email address instead. See our documentation for more information.",
      "name": "validation_error"
    }
    ```

    I manually sent out this edition, and fixed the sign-up processing code to
    ignore these kinds of emails for the future.

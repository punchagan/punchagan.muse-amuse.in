-  AI Delulu, minions and more

    Watched this [Ruby conf talk by DHH](https://www.youtube.com/watch?v=vDjW_dRyKXY) (shared by Voodoo) on how things are amazing
    for him, and how he's excited about not having to write a single line of code
    by hand, and yet building everything he can think of!

    It is great to be able to build things that we previously didn't have time to
    build or wouldn't care to do. But, what about my own understanding and
    learning? I have been building away more of Saa's art CMS, and it has been nice
    making a bunch of progress on it. Most of it is regular CRUD stuff that
    would've seemed like busywork to me if I had to write it all by hand. So, I'm
    definitely excited about the "things I'm not writing" (courtesy: DHH). I can
    also get Claude to write some experimental throwaway scripts to see if there's
    a way to categorize pieces for sale into different tiers based on how much
    "detail" there is, in them, for instance. It would've taken me long enough to
    write this by hand that, it probably would've remained a fun experiment to try
    for a long time if I had no code writing minions.

    But, did I learn any new colour theory ideas/concepts, or how vector PDFs store
    data as opposed to raster ones, or anything like that, which I would've if I
    wrote this by hand? Hell no!
